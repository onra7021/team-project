# team-project
###프로젝트 소개
음악 취향과 현재 기분을 바탕으로 한 6개의 질문을 통해 플레이리스트를 추천하는 웹사이트입니다.  락(Rock), 팝(Pop), 발라드(Ballad), R&B 중 하나의 음악 플레이리스트를 추천합니다.
---
###주요기능
음악 취향 테스트: 6개의 질문을 통하여 사용자의 음악 취향 파악

장르 추천: 테스트 결과에 따라 락, 팝, 발라드, R&B 중 하나의 장르 추천

플레이리스트 제공: 추천된 장르에 어울리는 음악 목록 제공

취향별 결과 안내: 추천 장르와 플레이리스트에 대한 간단한 설명과 특징 제공
